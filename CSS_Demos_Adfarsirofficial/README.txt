CSS PRACTICAL DEMOS | @adfarsirofficial
======================================

Open any .html file in Chrome. No installation, internet, libraries,
or external CSS files are required.

FOLDERS
01_Media_Queries: resize Chrome or use DevTools Device Toolbar.
02_CSS_Transforms: hover over the square; change transform values.
03_CSS_Transitions: hover; compare speed, delay, and easing.
04_CSS_Animations: watch animation and change the keyframe values.
05_CSS_Filters_and_Blend_Modes: compare before/after samples.

Each HTML file has internal CSS and short comments. Edit values,
refresh Chrome, and compare the output.

TIP: F12 (or right-click > Inspect) opens Chrome DevTools.
For responsive demos, toggle the device toolbar in DevTools.

Note: the print-media demo uses a small inline onclick handler only
to open the browser's native Print preview. All CSS examples otherwise
work without JavaScript.
